# ◈ Installation & Setup

## ① Clone Repository

```bash
git clone https://github.com/your-username/your-portfolio.git
```

---

## ② Navigate to Project

```bash
cd your-portfolio/app/frontend
```

---

## ③ Install Dependencies

```bash
npm install
```

---

## ④ Start Development Server

```bash
npm run dev
```

---

## ⑤ Build for Production

```bash
npm run build
```
