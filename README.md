#  Installation & Setup

## 1️. Clone Repository

```bash
git clone https://github.com/your-username/your-portfolio.git
```

---

## 2️. Navigate to Project

```bash
cd your-portfolio/app/frontend
```

---

## 3️. Install Dependencies

```bash
npm install
```

---

## 4️. Start Development Server

```bash
npm run dev
```

---

## 5️. Build For Production

```bash
npm run build
```
